GetRegistrationId<TLimit, TActivatorData>(IRegistrationBuilder<TLimit, TActivatorData, SingleRegistrationStyle>)

Gets the unique System.Guid identity assigned to a single-component registration.

public static Guid GetRegistrationId<TLimit, TActivatorData>(this IRegistrationBuilder<TLimit, TActivatorData, SingleRegistrationStyle> registration)

Parameters

registration IRegistrationBuilder<TLimit, TActivatorData, SingleRegistrationStyle>

The registration whose identity to retrieve.

Returns

Guid

The System.Guid that uniquely identifies this registration. This is the same value that will appear on the resulting Id after the container is built.

Type Parameters

TLimit

Registration limit type.

TActivatorData

Activator data type.

Remarks

Each single-component registration (created via RegisterType<TImplementer>(ContainerBuilder), Register<T>(ContainerBuilder, Func<IComponentContext, T>), or RegisterInstance<T>(ContainerBuilder, T)) is assigned a stable System.Guid at the time the registration builder is created. This ID flows through unchanged to Id when the container is built.

A common use case is to capture the registration ID before building the container and use it as a key in Properties to associate per-registration state or metadata, then look that state up at resolve time via Id.

This method is only available for single-component registrations (SingleRegistrationStyle). Multi-component registrations such as open-generic registrations (via RegisterGeneric), assembly-scanning registrations, adapters, and decorators do not have a single stable identity and this method is not callable on them — attempting to do so results in a compile-time error.

Exceptions

ArgumentNullException

Thrown if registration is null.
