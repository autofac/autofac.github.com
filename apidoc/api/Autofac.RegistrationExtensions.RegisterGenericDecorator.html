RegisterGenericDecorator(ContainerBuilder, Type, Type, object, object?)

Decorate all components implementing open generic service decoratedServiceType. The fromKey and toKey parameters must be different values.

[RequiresDynamicCode("Registering an open generic decorator constructs closed generic types at runtime via MakeGenericType, which may require dynamic code generation when closed over value types and is not compatible with native AOT.")]
public static IRegistrationBuilder<object, OpenGenericDecoratorActivatorData, DynamicRegistrationStyle> RegisterGenericDecorator(this ContainerBuilder builder, Type decoratorType, Type decoratedServiceType, object fromKey, object? toKey = null)

Parameters

builder ContainerBuilder

Container builder.

decoratorType Type

The type of the decorator. Must be an open generic type, and accept a parameter of type decoratedServiceType, which will be set to the instance being decorated.

decoratedServiceType Type

Service type being decorated. Must be an open generic type.

fromKey object

Service key or name associated with the components being decorated.

toKey object

Service key or name given to the decorated components.

Returns

IRegistrationBuilder<object, OpenGenericDecoratorActivatorData, DynamicRegistrationStyle>

The decorator registration for continued configuration.
