EnableClassInterceptors<TLimit, TRegistrationStyle>(IRegistrationBuilder<TLimit, ScanningActivatorData, TRegistrationStyle>)

Enable class interception on the target type. Interceptors will be determined via InterceptAttribute on the class or added with InterceptedBy<TLimit, TActivatorData, TStyle>(IRegistrationBuilder<TLimit, TActivatorData, TStyle>, params string[]). Only virtual methods can be intercepted this way.

public static IRegistrationBuilder<TLimit, ScanningActivatorData, TRegistrationStyle> EnableClassInterceptors<TLimit, TRegistrationStyle>(this IRegistrationBuilder<TLimit, ScanningActivatorData, TRegistrationStyle> registration)

EnableClassInterceptors<TLimit, TRegistrationStyle>(IRegistrationBuilder<TLimit, ScanningActivatorData, TRegistrationStyle>, Func<Type, bool>)

Enable class interception on the target type, conditionally based on the implementation type. Interceptors will be determined via InterceptAttribute on the class or added with InterceptedBy<TLimit, TActivatorData, TStyle>(IRegistrationBuilder<TLimit, TActivatorData, TStyle>, params string[]). Only virtual methods can be intercepted this way.
