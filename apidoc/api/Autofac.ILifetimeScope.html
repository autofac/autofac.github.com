Interface ILifetimeScope

Namespace
Autofac
Assembly
Autofac.dll

An ILifetimeScope tracks the instantiation of component instances. It defines a boundary in which instances are shared and configured.

Disposing an ILifetimeScope will dispose any components that were newly created when resolving from it, provided those components were not registered as ExternallyOwned().

Examples

// See IContainer for definition of the container variable
using (var requestScope = container.BeginLifetimeScope())
{
    // Note that handler is resolved from requestScope, not
    // from the container:

    var handler = requestScope.Resolve<IRequestHandler>();
    handler.Handle(request);

    // When requestScope is disposed, all resources used in processing
    // the request will be released.
}

Remarks

All long-running applications should resolve components via an ILifetimeScope. Choosing the duration of the lifetime is application- specific.

The standard Autofac integrations are already configured to create and dispose ILifetimeScopes as appropriate. For example, the integration with ASP.NET Core (via the .NET DI library) will create and dispose one ILifetimeScope per HTTP request.

Most ILifetimeScope functionality is provided by extension methods on the inherited IComponentContext interface.

Properties

Disposer

Gets the disposer associated with this ILifetimeScope. Component instances can be associated with it manually if required.

Tag

Gets the tag applied to the ILifetimeScope.

Methods

BeginLifetimeScope()

Begin a new nested scope. Component instances created via the new scope will be disposed along with it.

BeginLifetimeScope(Action<ContainerBuilder>)

Begin a new nested scope, with additional components available to it. Component instances created via the new scope will be disposed along with it.

BeginLifetimeScope(object)

Begin a new nested scope. Component instances created via the new scope will be disposed along with it.

BeginLifetimeScope(object, Action<ContainerBuilder>)

Begin a new nested scope, with additional components available to it. Component instances created via the new scope will be disposed along with it.

BeginLoadContextLifetimeScope(object, AssemblyLoadContext, Action<ContainerBuilder>)

Begin a new tagged sub-scope, with additional components available to it that may be dynamically loaded from the provided System.Runtime.Loader.AssemblyLoadContext. Component instances created via the new scope will be disposed along with it.

BeginLoadContextLifetimeScope(AssemblyLoadContext, Action<ContainerBuilder>)

Begin a new anonymous sub-scope, with additional components available to it that may be dynamically loaded from the provided System.Runtime.Loader.AssemblyLoadContext. Component instances created via the new scope will be disposed along with it.

Events

ChildLifetimeScopeBeginning

Fired when a new scope based on the current scope is beginning.

CurrentScopeEnding

Fired when this scope is ending.

ResolveOperationBeginning

Fired when a resolve operation is beginning in this scope.
