GetType(IConfiguration, string, Assembly?)

Loads a type by name.

public static Type GetType(this IConfiguration configuration, string key, Assembly? defaultAssembly)

Parameters

configuration IConfiguration

The Microsoft.Extensions.Configuration.IConfiguration object containing the type value to load.

key string

Name of the System.Type to load. This may be a partial type name or a fully-qualified type name.

defaultAssembly Assembly

The default System.Reflection.Assembly to use in type resolution if key is a partial type name.

Returns

Type

The resolved System.Type based on the specified name.

Exceptions

ArgumentNullException

Thrown if configuration is null.

InvalidOperationException

Thrown if the specified key can't be resolved as a fully-qualified type name and isn't a partial type name for a System.Type found in the defaultAssembly.
