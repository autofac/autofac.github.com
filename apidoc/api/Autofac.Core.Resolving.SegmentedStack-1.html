Class SegmentedStack<T>

Namespace
Autofac.Core.Resolving
Assembly
Autofac.dll

Implements a segmented stack of items, which functions like a regular System.Collections.Generic.Stack<T>, but allows segments of the stack to be enumerated without including items pushed before the segment.
