public AutoFake(bool strict = false, bool callsBaseMethods = false, Action<object>? configureFake = null, Action<ContainerBuilder>? configureAction = null)

Parameters

strict bool

true to create strict fakes. This means that any calls to the fakes that have not been explicitly configured will throw an exception.

callsBaseMethods bool

true to delegate configured method calls to the base method of the faked method.

configureFake Action<object>

Specifies an action that should be run over a fake object before it's created.

configureAction Action<ContainerBuilder>

Specifies actions that need to be performed on the container builder, like registering additional services. Use this to provide specific dependency instances or implementations to the system under test (for example, configureAction: b => b.RegisterInstance(myDependency).As<IDependency>()).
