CreateServiceHost(string, Uri[])

Creates a System.ServiceModel.ServiceHost with the specified base addresses and initializes it with the specified data.

public override ServiceHostBase CreateServiceHost(string constructorString, Uri[] baseAddresses)

Parameters

constructorString string

The initialization data passed to the host being constructed.

baseAddresses Uri[]

The base addresses for the hosted service.

Returns

ServiceHostBase

A System.ServiceModel.ServiceHost with the specified base addresses.

Remarks

If HostConfigurationAction is not null, the new host is run through it before being returned.

Exceptions

ArgumentNullException

Thrown if constructorString or baseAddresses is null.

ArgumentException

Thrown if constructorString is empty.

InvalidOperationException

Thrown if Container is null.
