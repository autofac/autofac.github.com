RegisterServiceFabricSupport(ContainerBuilder, Action<ILifetimeScope, Exception>?, Action<ContainerBuilder>?)

Adds the core services required by the Service Fabric integration.

public static void RegisterServiceFabricSupport(this ContainerBuilder builder, Action<ILifetimeScope, Exception>? constructorExceptionCallback = null, Action<ContainerBuilder>? configurationAction = null)

Parameters

builder ContainerBuilder

The container builder to register the services with.

constructorExceptionCallback Action<ILifetimeScope, Exception>

Callback will be invoked if an exception is thrown during resolving. The ILifetimeScope that was created for the service is passed to the callback so dependencies (a logger, for example) can be resolved from it. The scope is disposed after the callback completes.

configurationAction Action<ContainerBuilder>

Callback will be invoked while configuring the lifetime scope for a service.
