EnableInterfaceInterceptors<TLimit, TActivatorData, TSingleRegistrationStyle>(IRegistrationBuilder<TLimit, TActivatorData, TSingleRegistrationStyle>, Func<Type, bool>)

Enable interface interception on the target type, conditionally based on the resolved implementation type. Interceptors will be determined via InterceptAttribute on the class or interface, or added with InterceptedBy<TLimit, TActivatorData, TStyle>(IRegistrationBuilder<TLimit, TActivatorData, TStyle>, params string[]).

public static IRegistrationBuilder<TLimit, TActivatorData, TSingleRegistrationStyle> EnableInterfaceInterceptors<TLimit, TActivatorData, TSingleRegistrationStyle>(this IRegistrationBuilder<TLimit, TActivatorData, TSingleRegistrationStyle> registration, Func<Type, bool> shouldIntercept)

Parameters

registration IRegistrationBuilder<TLimit, TActivatorData, TSingleRegistrationStyle>

Registration to apply interception to.

shouldIntercept Func<Type, bool>

A predicate, evaluated against the resolved implementation type, that determines whether interception is applied. When the predicate returns false the resolved instance is returned without a proxy.
